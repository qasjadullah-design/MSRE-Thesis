# Handoff format

For each task, provide:

- Issue ID, agent, status, branch and commit/PR URL.
- Objective, work completed, and precise files changed.
- Source documents, dates, clauses, and evidence confidence.
- Commands executed, solver/dependency versions, tests passed/failed; if none, say none.
- Assumptions, open decisions and blockers.
- Next small assignment and recommended reviewer.

No invented test results. Do not edit this single file concurrently: put per-task handoffs in PR descriptions or governance/handoffs/TH-xxx.md.
